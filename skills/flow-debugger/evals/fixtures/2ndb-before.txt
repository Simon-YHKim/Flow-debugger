아래는 기능 흐름도(flow-debugger)에서 내가 수집한 작업 요청 목록이야.
각 항목의 코드 근거(route, file:line, api 태그)를 참고해서 — 흐름도 설명이 틀렸으면 정정하고, 코드 수정이 필요하면 고쳐줘.

1. [버그] 동작 "화면을 연다" — 화면 첫 통찰  (코드: markTTFVSeen @ src/app/ttfv.tsx:13)
   → 증상: 첫 기록을 저장했는데 별이 안 생겨요 · 기대: 저장하면 화면에 별이 하나 떠야 해요 · 코드 경로부터 원인을 찾아 고쳐줘
2. [버그] 동작 "화면을 연다" — 화면 로그인  (코드: useSignInForm (userId/loading) @ src/app/(auth)/sign-in.tsx:72)
   → 증상: 로그인 버튼을 눌러도 아무 반응이 없어요 · 기대: 이메일/비번 맞으면 홈으로 넘어가야 해요 · 코드 경로부터 원인을 찾아 고쳐줘
3. [메모] 화면 "담기"  (코드: src/... (screen))
   → 이름(라벨)을 "빠른 담기"(으)로 바꿔줘
4. [추가] 새 화면 "알림 설정 화면" — 담기에 연결
   → 이런 화면이 새로 필요해 — 만들어줘: 푸시 알림을 켜고 끌 수 있어야 해요
5. [연결] 연결 추가: 첫 기록 → 홈 별자리
   → 이 연결이 실제 코드에 있는지 확인하고 흐름도에 반영해줘
